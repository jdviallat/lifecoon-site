# lifecoon-site

Page de présentation publique de l'application **Lifecoon — Suivi Santé** (par Bengacoon).

- `index.html` — page d'accueil (présentation, fonctions, confidentialité).
- `privacy.html` — politique de confidentialité (FR + EN).
- `assets/` — icône et favicon.

Site statique servi par **GitHub Pages**. Aucune donnée collectée.

- **iOS** : App Store.
- **Android** : APK direct via [lifecoon-updates](https://github.com/jdviallat/lifecoon-updates/releases/latest).
