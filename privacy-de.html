Datenschutzerklärung

Keine erhobenen Daten, kein Konto, keine Werbung. Alles bleibt verschlüsselt auf Ihrem Gerät.

Letzte Aktualisierung: Juli 2026 · Herausgeber: Bengacoon

Lifecoon („die Anwendung") ist ein persönliches Gesundheitstagebuch, das unter voller Achtung Ihrer Privatsphäre entwickelt wurde.

Keine Datenerhebung

Die Anwendung erhebt, übermittelt und teilt keinerlei personenbezogene oder Gesundheitsdaten. Sie erfordert keine Kontoerstellung und verlangt keine Anmeldung.

Ihre Daten bleiben auf Ihrem Gerät

Alle Informationen, die Sie eingeben (Profil, Messwerte für Blutdruck / Blutzucker / Gewicht und weitere Werte, Behandlungen, Verordnungen, Geräte, Termine, Dokumente, Tagebuch), werden ausschließlich lokal auf Ihrem Gerät in einer verschlüsselten Datenbank gespeichert. Sie werden niemals an einen Server gesendet. Sie können sie jederzeit exportieren (verschlüsselte Sicherungsdatei), importieren oder vollständig löschen über die Einstellungen der Anwendung.

Keine Tracker, keine Werbung

Die Anwendung enthält keine Tracking-, Analyse- oder Werbewerkzeuge von Drittanbietern.

Überprüfung von Aktualisierungen

Die Anwendung kann prüfen, ob eine neue Version verfügbar ist, indem sie eine öffentliche Datei abfragt, die auf GitHub gehostet wird. Diese Anfrage übermittelt keinerlei personenbezogene Daten; es wird lediglich die verfügbare Versionsnummer abgerufen.

Benachrichtigungen, Biometrie & Gesundheit

Wenn Sie sie aktivieren, werden die Erinnerungen (Medikamenteneinnahme, Messungen, Termine, Untersuchungen) lokal auf Ihrem Gerät erzeugt. Die Sperrung per Face ID / Touch ID / Fingerabdruck wird vom System Ihres Geräts verarbeitet; Lifecoon erhält niemals Ihre biometrischen Daten. Der Import aus Apple Health / Health Connect erfolgt, sofern Sie ihn erlauben, schreibgeschützt und lokal; diese Daten verlassen das Gerät nicht.

Kalendersynchronisierung (optional)

Wenn Sie die Synchronisierung eines Termins mit einem Kalenderkonto (CalDAV) einrichten, werden nur die Informationen des betreffenden Termins an den Kalenderserver gesendet, den Sie selbst angegeben haben. Ohne Konfiguration wird nichts gesendet.

Kostenlos

Lifecoon ist vollständig kostenlos, ohne Abonnement und ohne In-App-Käufe. Es werden keine Zahlungsdaten verlangt oder verarbeitet.

Kinder

Die Anwendung richtet sich nicht speziell an Kinder und erhebt keine Daten über sie.

Gesundheitshinweis

Lifecoon ist ein persönliches Gesundheitstagebuch. Es stellt keine Diagnose, ist keine Behandlung und ersetzt nicht den Rat einer medizinischen Fachkraft. Die Warnungen beruhen ausschließlich auf den von Ihnen festgelegten Schwellenwerten.
